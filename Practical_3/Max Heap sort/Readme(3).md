# Max Heap Sort - Time and Space Complexity

| Algorithm | Best Case | Average Case | Worst Case | Space Complexity |
|-----------|-----------|--------------|------------|------------------|
| Max Heap Sort | O(n log n) | O(n log n) | O(n log n) | O(1) |

## Max Heap Sort

- **Best Case:** O(n log n)
- **Average Case:** O(n log n)
- **Worst Case:** O(n log n)
- **Space Complexity:** O(1)
- **Stable:** No
- **In-place:** Yes

## Conclusion

- **Max Heap Sort** provides consistent O(n log n) time complexity in all cases.
- It does not require extra memory for another array, so its space complexity is **O(1)**.
- It is an **in-place sorting algorithm**.
- Heap Sort is useful when guaranteed O(n log n) performance and low extra memory usage are required.
- Unlike Quick Sort, Heap Sort does not have an O(n²) worst-case time complexity.

### Note

Max Heap Sort has **O(n log n)** time complexity in all cases and **O(1)** auxiliary space when implemented in-place.
